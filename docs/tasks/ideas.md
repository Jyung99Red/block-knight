## 4. 武器锻造和升级路线（草案 2026-10-09，用户还没定）

只是方案，没有写代码。下面凡写"推荐"的，都等用户在 4.7 拍板；定了的再搬进 `design.md` 7.2 / 7.3。

### 4.1 升级路线

守 `design.md` 7.1"没有强化"：不做 +N，升级是**用素材锻出下一阶的另一件装备**（魔物猎人升级树的做法，但不分叉）。
一阶对应一个地区和一个首领，让"为什么要去下一个地方"有答案：

| 阶 | 什么时候 | 主要素材 | 武器的打铁站数 | 剑 / 短刃 / 盾 / 甲 |
|---|---|---|---:|---|
| 木 | 开局 | | | 木剑 / — / 木盾 / 布甲 |
| 铁 | 晨雾原野、采矿 | 铁矿石、哥布林耳、狼皮（现有配方） | 3 | 铁剑 / 刺客短刃 / 铁盾 / 铁甲（已有） |
| 钢 | 打倒哥布林头目后 | 更多铁矿石、头目獠牙（坟墓能让首领复活再打，素材不会断）、木炭？ | 5 | 钢剑 / 钢刃 / 钢盾 / 钢甲 |
| 百炼 | 打倒狼王、进千柱窟 | 狼王之牙、晶石、蛛丝 | 7 | 百炼剑 / 百炼刃 / 百炼盾 / 百炼甲 |

- 名字都是暂定。盾和甲只打烧红、锻打两站（钢阶起加正火）；饰品不进小游戏，照旧点一下打造。
- 蛛丝现在只能卖，百炼阶拿来缠柄、做甲里衬；晶石镶在护手或柄头。头目獠牙和狼王之牙现在做饰品，阶梯也要用，数量不够就让饰品配方少要一点。
- 同类型武器只在攻击力上不同、一样长（`design.md` 4.2）：升级改攻击和外观（刃色、护手、柄缠、镶晶、刃纹），不碰招式表和刃长。
  每阶大约 +8 攻击，具体对着怪调（`roadmap.md` 之后第 5 条）；短刃同阶比剑低一些（现在 11 对 16，本来就快）。
- 升级用掉上一阶（推荐）：仓库就是背包，留着只占位。**武器熟练度**（`design.md` 1，还没做）因此要记在武器类型（剑 / 短刃）上，不记在某一把上，否则一升级就归零。

### 4.2 品质（小游戏的产出）

- 3 档：粗制 / 良品 / 精品。影响外观（刃面光泽、刃纹出现、柄饰），可能还带很小的攻击浮动（推荐，见 4.7）。
- 每件装备 `max` 是 1，品质可以直接记成"装备 id → 档位"存进存档，背包不用改成一件一件的实例。
- **失败不丢素材**：最差是粗制品。想改好就**重铸**，只收金币、不收素材，打出来更好才换。给金币一个去处，也不鼓励反复刷素材（上面第 2 节提过刷素材的味道）。
- 做出过精品的配方，之后可选"快速锻造"直接出良品，不用每次都打一遍（推荐）。

### 4.3 小游戏怎么玩

- 在铁匠铺的界面里打，游戏停住（同商店）。横屏手机，**不新增控件**，沿用现在五个键的位置，肌肉记忆是现成的：

  | 键 | 锻造里 |
  |---|---|
  | 摇杆 | 左右移动击点（坯料的尖、身、根）；淬火时把坯料竖直拖进水槽 |
  | 攻击键（右下最大） | 锤：轻点是轻锤（A），按住再松开是重锤（B）；谱面就用 A、B 拼，和连段是同一套说法 |
  | 格挡键 | 按住拉风箱（升温），松开慢慢降温 |
  | 副手键 | 翻面、回炉、出炉、撒焊剂 |

- 一次打造 = 若干站，按阶增加：铁阶约 30～40 秒，钢阶约 1 分钟，百炼阶约 1 分半。
- 声音是主要的反馈：锤声随温度变（热时闷，冷了脆），好的一锤有火花，差的没有；颜色比数字重要，默认只显示颜色，设置里可开温度读数（推荐）。
- 真实的几小时压成几秒（烧红约 1.5～2 分钟压成按住 4～6 秒，回火 2 × 1 小时压成 2 × 约 4 秒），但顺序、先后、窗口的宽窄跟真的一样。

### 4.4 工序对照（硬核部分）

"水遂火"我按**淬火**理解（烧红了入水）。数字是量级，各来源不完全一致，见 4.5。

**先答：烧多久？** 没有固定时间，看颜色，还看料多粗、炉子多旺。能查到的一个数据：一根软钢棒在煤火里约 1.5～2 分钟烧到橙黄。
暗红（约 600 ℃）只是刚发光，锻就太冷了；亮红约 800 ℃；**橙到黄（约 850～1000 ℃，也有说到 1100 ℃）才是锻打温度**。变回暗红就该停手回炉。过头比不够更糟：白热、爆火花就是烧毁了，表面的碳先烧掉。

1. **烧红（入炉）**
   - 真实：上面那段。太冷锻会裂，太热会像干酪一样碎。每回炉一次，氧化皮和脱碳都要损耗一点。
   - 游戏：按住格挡键拉风箱，颜色条从暗红 → 橙 → 黄，落进橙黄带松手；到白就爆火花。
   - 出错：太冷，锤下去"裂"；太热，烧损。都扣品质，不毁素材。
2. **锻打**
   - 真实：趁橙黄打，红了就回炉，反复多次，把料拉成形。
   - 游戏：摇杆选击点，攻击键跟拍子；坯料颜色随时间从黄掉到红，锤声变脆，就该回炉。回炉要重新烧一遍，次数有上限，回炉多了扣品质。打偏则坯料歪。
3. **折叠锻接（百炼阶）**
   - 真实：锻接要到淡黄（约 1200～1260 ℃，含碳高的更低），再高就爆火花。撒硼砂当助焊剂，到锻接热时它像水一样冒泡流动；出炉后只有 5～6 秒，从中间往外打，免得把焊剂封在里头；每折一次重撒一次。焊好后炉火压到约 1050～1090 ℃ 再成形，太冷会把焊缝震开。日本刀折叠约 14 次，约一万六千层。
   - 游戏：副手键撒焊剂 → 烧到锻接热（黄带最窄，旁边就是火花）→ 出炉后 5 秒内连打一小段谱。每折一次层数加倍，决定刃面纹理。
4. **正火（钢阶起）**
   - 真实：三遍一遍比一遍低的加热，约 900 ℃ → 845 ℃ → 790 ℃，每遍均匀后放在空气里冷到暗；后一遍不要比前一遍更热。目的是细晶粒、消内应力。三遍之后收益递减；也有人说一遍就够（论坛，意见不一）。
   - 游戏：三次"烧到目标色 → 出炉放凉"，目标色一次比一次低（橙 → 浅橙 → 樱桃红）；放凉那几拍是空拍，手别乱按。
5. **淬火**
   - 真实：先烧到**磁铁吸不住**（约 765～775 ℃），再稍高一点、均匀，保温几分钟（一个来源说 2～3 分钟，没查到统一的）；论坛里 1095 钢约 775～790 ℃。日本刀在暗室里看炭火光判断颜色，约 750～800 ℃，刃口薄涂泥、背厚涂泥：刃冷得快成硬的马氏体，背冷得慢保持韧，对比出刃纹。
     冷却：**盐水最猛，水次之，油最稳**。水易裂易翘（蒸汽膜塌陷得很猛）；论坛里的稳妥做法是 38～49 ℃ 的 3～5% 盐水，或不高于 54 ℃ 的油，淬 7～12 秒，降到约 200 ℃ 以下再取。入淬要竖直上下、不侧摆；单刃刃口先，双刃尖先（论坛有争论）。
     中断淬火：入 2～3 秒取出，趁热校直（窗口约 2～3 分钟，过了就脆），再入。**淬完尽快回火，别拖**（有人直接从淬火槽进烘箱，也有人凉了再回火，都说别拖）。
   - 游戏：先选介质（水：高分高风险；油：稳）和涂泥（厚薄决定刃纹）→ 烧到樱桃红的窄带（太低没淬硬成软刀，太高晶粒粗、脆）→ 出炉后在窗口内把坯料竖直拉进水槽：横向晃动 = 翘曲，拉太慢 = 温度掉出窗口。滋滋声停了取出，短窗口里点翘处校直。
   - 出错：软、裂、翘，三种，各扣品质。
6. **回火**
   - 真实：淬完很脆，要回火。氧化色：淡麦黄约 200～230 ℃，暗金约 240 ℃，再到梅紫，蓝约 290～315 ℃。烘箱法 175～230 ℃，**做两遍**，每遍约 1 小时，中间凉到室温。传统分区：刃口留麦黄（硬），脊背到梅色（软而韧）。颜色过头了就是回软了，要回去重淬。
     颜色表本身有约 ±100 ℃ 的误差，换灯光颜色也变。
   - 游戏：两遍。按住攻击键加热，看氧化色一点点变（麦黄 → 金 → 紫 → 蓝），在目标色松手。过头就退回淬火那一站重来，且这件品质最高到良品。
7. **磨刃（百炼阶）**
   - 真实：先粗后细，刮掉氧化皮；日本刀抛光约 1～3 周。
   - 游戏：沿刃身来回滑三遍（粗 → 中 → 细），拍子很松，主要是回报：刃纹和光泽一点点显出来。

### 4.5 来源和可信度

多数来源是爱好者论坛和教程，不是金相手册，数字当量级看；颜色和温度的对应表本身有 ±110 ℃ 的误差。
两个页面（大都会博物馆的日本刀文章、日本政府的英文资料）在这个容器里打不开，日本刀的 750 ℃ / 800 ℃ 来自搜索摘要，没有核对原文。
"二月八月的水温"和"蒲元用蜀江水淬刀"（水质决定刀好坏）两个传说没查到可靠出处，没用进工序；可以当铁匠铺的台词。

- 日本刀：[大都会博物馆](https://www.metmuseum.org/essays/the-japanese-blade-technology-and-manufacture)、[日本刀怎么做](https://japanesesword.net/blogs/news/how-a-japanese-sword-is-made-from-iron-sand-to-finished-blade)
- 锻造温度和颜色：[BlacksmithU](https://blacksmithu.com/how-blacksmiths-measure-temperature/)、[Carleton 实验数据](https://222.arcn.sites.carleton.edu/lab-group-data/group-a-week-7-lab-data-blacksmithing/)、[iForgeIron：heats](https://www.iforgeiron.com/topic/1008-heats/)、[Blade Forums：forging color](https://www.bladeforums.com/threads/forging-color.499813/)、[anvilfire：colors of the forge](https://anvilfire.com/21st-century-blacksmithing/colors-of-the-forge)

### 4.6 做的时候会碰到的

- 小游戏的规则（站的顺序、温度曲线、判定、品质怎么算）放 `core/`：没有 DOM，时间由外面注入，Node 测试能跑；界面放 `ui/`。
- 每个配方写出自己要哪几站，数值全进 `game_config.js`，同步 `docs/parameters.md`。
- 存档加一项品质；装备栏和背包显示品质，人物模型按品质换颜色。
- 做的顺序（每一步都让用户在手机上试手感）：
  1. 小游戏骨架 + 铁阶 3 站（烧红、锻打、淬火）+ 品质只改外观；
  2. 钢阶：加正火、回火，新一阶装备和配方；
  3. 百炼阶：折叠锻接、磨刃，蛛丝和晶石有用处；
  4. 重铸、快速锻造；品质带不带攻击浮动，按用户的决定。

### 4.7 要用户定的

1. 升级**用掉**上一阶（推荐），还是留着？
2. 品质只改外观，还是外观加很小的攻击浮动（推荐；用户说过想要新样子，不只是多几点数值）？
3. 要不要一个新素材**木炭**（带火把烧枯木丛得到）当钢的前置？不要的话钢阶用更多铁矿石顶。这是新增掉落，先问。
4. 做出过精品后可以"快速锻造"，还是每次都打（推荐前者）？
5. 默认只显示颜色、设置里可开温度读数（推荐），还是一开始就给数字？
6. 三阶 3 / 5 / 7 站会不会太长；先做铁阶那 3 站试手感，再决定往上加多少。
