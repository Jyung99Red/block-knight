## 4. 武器锻造和升级路线（草案 2026-10-09）

用户 2026-10-09 已定的，已写进 `design.md` 7.4：升级用掉上一阶；品质影响少量属性和外观（颜色的鲜艳度）；允许少量的刷。
木炭素材等下再看，先不要。其余都还是方案，没有写代码。

用户对第一版的意见：**步骤太多，而且多数时间在看温度，很少锤铁。** 所以这一版的原则：锤是主角，温度只是锤的时候的一个条件，不再是单独的一站。

### 4.1 升级路线

守 `design.md` 7.1"没有强化"：不做 +N，升级是用素材锻出下一阶的另一件装备，上一阶用掉（用户 2026-10-09）。
一阶对应一个地区和一个首领，让"为什么要去下一个地方"有答案：

| 阶 | 什么时候 | 主要素材 | 小游戏里多出来的东西 | 剑 / 短刃 / 盾 / 甲 |
|---|---|---|---|---|
| 木 | 开局 | | | 木剑 / — / 木盾 / 布甲 |
| 铁 | 晨雾原野、采矿 | 铁矿石、哥布林耳、狼皮（现有配方） | 只有轻锤，拍子稳 | 铁剑 / 刺客短刃 / 铁盾 / 铁甲（已有） |
| 钢 | 打倒哥布林头目后 | 更多铁矿石、头目獠牙 | 加重锤，拍子会变，坯料更容易冷 | 钢剑 / 钢刃 / 钢盾 / 钢甲 |
| 百炼 | 打倒狼王、进千柱窟 | 狼王之牙、晶石、蛛丝 | 加折叠段（一小段密集连打） | 百炼剑 / 百炼刃 / 百炼盾 / 百炼甲 |

- 名字都是暂定。盾和甲走同一个小游戏，谱面更短；饰品不进小游戏，照旧点一下打造。
- 蛛丝现在只能卖，百炼阶拿来缠柄、做甲里衬；晶石镶在护手或柄头。头目獠牙和狼王之牙现在做饰品，阶梯也要用，数量不够就让饰品配方少要一点。
- 同类型武器只在攻击力上不同、一样长（`design.md` 4.2）：升级改攻击和外观（刃色、护手、柄缠、镶晶、刃纹），不碰招式表和刃长。
  每阶大约 +8 攻击，具体对着怪调（`roadmap.md` 之后第 5 条）；短刃同阶比剑低一些（现在 11 对 16，本来就快）。
- 上一阶用掉，所以**武器熟练度**（`design.md` 1，还没做）要记在武器类型（剑 / 短刃）上，不记在某一把上，否则一升级就归零。

### 4.2 品质

- 3 档：粗制 / 良品 / 精品。影响少量属性（比如 ±5%，具体调）和外观：同一个颜色名，粗制偏灰暗，精品更鲜亮、刃上有光（用户：可能是颜色的鲜艳度）。
  颜色仍然写颜色名（`design.md` 2.1），鲜艳度是画的时候对颜色做的调整，不是新的色值。
- 每件装备 `max` 是 1，品质记成"装备 id → 档位"存进存档，背包不用改成一件一件的实例。
- 失败不丢素材，最差是粗制品。想改好就**重铸**：只收金币，不收素材，打出来更好才换。少量的刷落在金币上，素材不用再来一遍。
- "做出过精品后快速锻造"先不做，等玩起来看刷得难不难受再说。

### 4.3 小游戏（第二版：两站，锤是主角）

在铁匠铺的界面里打，游戏停住（同商店）。**每一阶都只有两站：锻打、淬火**；阶越高，差别在谱面，不在站数。

**锻打（占七成以上的时间）**

- 画面：横屏，砧上一块坯料居中，底下一条拍子轨，拍子从右往左滑到击点。坯料自己变色（黄 → 橙 → 红 → 暗），不用盯着条看。
- 一只手就能玩：攻击键跟拍，轻点是轻锤（A），按住再松开是重锤（B），谱面就用 A、B 拼，和连段是同一套说法。摇杆不用，坯料自己一段一段往前走。
- **温度藏在锤里**：
  - 坯料颜色决定判定窗口：黄时宽、软，一锤成形；红了变窄；暗了锤下去算"裂"，扣分。
  - 变红了谱面里会出现一个**入炉的休止**：按住格挡键，跟着风箱的拍子按，2～3 秒，颜色回到黄，接着锤。一次打造入炉 2～4 次，合起来不到三成时间，而且是跟着拍子按，不是干等。
  - 每入炉一次，氧化皮和脱碳要损耗一点（真的会），品质扣一点，所以要一口气多锤几下。
- 声音是主要反馈：锤声随温度变（热时闷，冷了脆），好的一锤有火花，差的没有。
- 分数 = 锤得准不准 + 是不是在热的时候锤 + 入炉次数少。
- 谱面随阶变深：铁阶只有轻锤、稳拍；钢阶加重锤、二连、休止；百炼阶加**折叠段**——副手键撒焊剂，烧到黄白，出炉后 5 秒的密集连打（真实锻接就只有 5～6 秒），一次打造折两三次，折得越多刃上纹理越细。

**淬火（5～8 秒，一次决定）**

- 先选水还是油：水高分高风险，油稳（真实里水最易裂易翘，油最稳）。这是"水遂火"的那一下，也是这个游戏里最硬核的取舍。
- 坯料出炉时樱桃红，颜色慢慢变暗：在对的颜色点一下出炉（早了还在橙，没到非磁性点；晚了变暗红，没淬硬），再把它**竖直向下**拖进水槽，横着晃就是翘。
- 淬完自动放一小段（约 3 秒，只看）：颜色从麦黄变到蓝再定住，磨一下，刃纹亮出来。回火、磨刃不做成站，结果由前两站的分数决定。

时长：铁阶约 35 秒，钢阶约 50 秒，百炼阶约 70 秒。

"硬核"留在这些地方：温度看颜色、冷了不能锤、入炉有代价、淬火的介质和出炉颜色、折叠的 5 秒窗口。正火、回火、磨刃只留在结尾动画和铁匠铺的台词里。
默认只显示颜色，设置里可以开温度读数。

### 4.4 工序对照（备查）

"水遂火"我按**淬火**理解（烧红了入水）。数字是量级，各来源不完全一致，见 4.5。

**烧多久？** 没有固定时间，看颜色，还看料多粗、炉子多旺。能查到的一个数据：一根软钢棒在煤火里约 1.5～2 分钟烧到橙黄。
暗红（约 600 ℃）只是刚发光，锻就太冷了；亮红约 800 ℃；**橙到黄（约 850～1000 ℃，也有说到 1100 ℃）才是锻打温度**。变回暗红就该停手回炉。
过头比不够更糟：白热、爆火花就是烧毁了，表面的碳先烧掉。太冷锻会裂，太热会像干酪一样碎。

| 工序 | 真实要点 | 游戏里 |
|---|---|---|
| 烧红、锻打 | 趁橙黄打，红了就回炉，反复多次；每回炉一次损耗一点 | 锻打站：坯料变色、入炉休止、入炉扣品质 |
| 折叠锻接 | 锻接热约 1200～1260 ℃（含碳高的更低），再高爆火花；撒硼砂当助焊剂，到锻接热时它像水一样冒泡；出炉后只有 5～6 秒，从中间往外打；每折一次重撒；焊好后炉火压到约 1050～1090 ℃ 再成形。日本刀折叠约 14 次，约一万六千层 | 百炼阶的折叠段 |
| 正火 | 三遍一遍比一遍低的加热，约 900 → 845 → 790 ℃，每遍在空气里冷到暗；目的是细晶粒、消内应力；三遍之后收益递减，也有人说一遍就够（论坛，意见不一） | 不做站，算进分数 |
| 淬火 | 先烧到磁铁吸不住（约 765～775 ℃）再稍高、均匀，保温几分钟（一个来源说 2～3 分钟）；论坛里 1095 钢约 775～790 ℃。日本刀在暗室里看炭火光判断颜色，约 750～800 ℃，刃口薄涂泥、背厚涂泥：刃冷得快成硬的马氏体，背冷得慢保持韧，对比出刃纹。冷却：盐水最猛，水次之，油最稳；论坛里的稳妥做法是 38～49 ℃ 的 3～5% 盐水，或不高于 54 ℃ 的油，淬 7～12 秒，降到约 200 ℃ 以下再取。入淬要竖直、不侧摆；单刃刃口先，双刃尖先（论坛有争论）。中断淬火：入 2～3 秒取出，趁热校直（窗口约 2～3 分钟，过了就脆），再入。淬完尽快回火，别拖 | 淬火站：选介质、出炉的颜色、竖直入水 |
| 回火 | 淬完很脆。氧化色：淡麦黄约 200～230 ℃，暗金约 240 ℃，再到梅紫，蓝约 290～315 ℃。烘箱 175～230 ℃，做两遍，每遍约 1 小时，中间凉到室温。传统分区：刃口留麦黄（硬），脊背到梅色（软而韧）。颜色过头了就是回软了，要重淬。颜色表有约 ±100 ℃ 的误差 | 结尾动画 |
| 磨刃 | 先粗后细，刮掉氧化皮；日本刀抛光约 1～3 周 | 结尾动画，刃纹亮出来 |

### 4.5 来源和可信度

多数来源是爱好者论坛和教程，不是金相手册，数字当量级看；颜色和温度的对应表本身有 ±110 ℃ 的误差。
两个页面（大都会博物馆的日本刀文章、日本政府的英文资料）在这个容器里打不开，日本刀的 750 ℃ / 800 ℃ 来自搜索摘要，没有核对原文。
"二月八月的水温"和"蒲元用蜀江水淬刀"（水质决定刀好坏）两个传说没查到可靠出处，没用进工序；可以当铁匠铺的台词。

### 4.6 做的时候会碰到的

用户说不知道小游戏玩起来会怎样，所以**把小游戏做成品质的一个来源，而不是整套升级的前提**：没有小游戏时品质一律是良品，升级路线照样能用；小游戏不好玩可以整个换掉或关掉，不用拆别的。

- 小游戏的规则（谱面、温度曲线、判定、品质怎么算）放 `core/`：没有 DOM，时间由外面注入，Node 测试能跑；界面放 `ui/`。
- 每个配方写出自己用哪份谱面，数值全进 `game_config.js`，同步 `docs/parameters.md`。
- 存档加一项品质；装备栏和背包显示品质，画装备时按品质调颜色鲜艳度。
- 做的顺序（每一步都让用户在手机上试）：
  1. 升级路线本身，不要小游戏：钢阶、百炼阶的装备和配方，上一阶用掉，品质字段和它对属性、颜色的影响（先都是良品，重铸可以手动试）。这一步就能看到升级的感觉；
  2. 铁阶的锻打（轻锤 + 入炉）+ 淬火，只做这一阶，试手感，不好玩就在这里改；
  3. 钢阶：重锤、变拍；
  4. 百炼阶：折叠段。
